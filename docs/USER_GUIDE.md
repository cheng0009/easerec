# 简录 EaseRec 用户使用手册

> **版本**: v0.2（Electron 版 · Hub 界面）
> **Slogan**: 简录，让知识输出回归纯粹。
> **定位**: 科技博主的实时录屏导播台 —— 录屏即成片
> 路线图见 [ROADMAP.md](ROADMAP.md)，技术架构见 [ARCHITECTURE.md](ARCHITECTURE.md)。

## 一、快速开始

### 1.1 环境要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10 21H2+（推荐 Windows 11） |
| 内存 | 8 GB（推荐 16 GB） |
| 磁盘 | 1 GB+ 可用空间 |
| 权限 | 普通用户权限即可（无需管理员） |

### 1.2 启动应用

```powershell
# 开发模式（构建主进程 + 启动 Vite 热更新 + 拉起 Electron）
cd AI_DirectorCam
npm run dev

# 构建/运行生产产物
npm run build
npm run build:electron
npm start
```

> 首次使用需保证项目内 `src-tauri/ffmpeg.exe` 存在（导出功能依赖，可用 `scripts/download-ffmpeg.ps1` 下载）。

## 二、界面概览（Hub）

标题栏双页签：**🎬 工作台**（录制现场）与 **📚 成片库**（历史录像档案）。

### 工作台

```
┌───────────┬──────────────────────────────────────────┐
│ 舞台准备   │   成片画布（实况预览 / 成片回放）          │
│ 🔔纯净舞台 │   叠层：LIVE 时长 · 实际分辨率/帧率        │
│ ✨导播特效 │   🖥 画面源选择（全屏 / 显示器 / 窗口）     │
│ 🎥摄像头   ├──────────────────────────────────────────┤
│ (一屏放下) │   胶片条: [片头+] [●主片·标记贴片] [片尾+] │
│           ├──────────────────────────────────────────┤
│           │  ⏺录制 ⏸暂停 00:00 ⏩ 🛡 🔒 📸     │
├───────────┴─────────────────────┬────────────────────────┤
│ ● 状态徽标（遮挡/快进/暂停）FPS   │  ⚙设置  [📦 导出成片]   │
└─────────────────────────────────┴────────────────────────┘
```

- **停止即回放**：录制停止后预览自动切换为成片回放，导出按钮开始呼吸提示。
- **胶片条即导出结构**：点击首尾的"片头 + / 片尾 +"附加视频；✂剪除、🛡遮挡、⏩快进标记实时落在胶片上；回放态点击胶片条跳转。
- **导出抽屉**：静音裁剪、响度归一、竖版 9:16、字幕（样式/热词/LLM 校正）、输出目录。
- **⚙ 设置**：快捷键（三组折叠）、帧率/分辨率/码率（下次开录生效）、音频源、输出目录。

### 成片库

所有录像以卡片展示（时长 / 大小 / 标记统计 / 未完成恢复），可一键打开回放、导出或定位目录。

## 三、## 三、功能详解

### 3.1 Focus Mode（F1）

一键"纯净舞台"：隐藏桌面图标 + 在最底层铺纯色背景，录制画面干净专业。
用 F1 随时切换。

### 3.2 智能跟焦（核心卖点：录轨迹，导出渲染）

录制时画面保持 1:1 原始流（零渲染负担，长录不卡顿），软件仅以约 30ms 间隔记录鼠标轨迹；**导出时**用离线相机重放（与实时预览同一套 SmartZoom + 弹簧相机算法）+ ffmpeg zoompan 逐帧渲染出平滑的镜头跟随与放大——鼠标停留处缓缓推近、移动时平滑跟焦、回到中央缓出全景。

- 预览区的蓝色虚线框 = 导出时的放大区域（所见即导出）。
- 设置 → 视频中可开关，并选择放大倍率（1.2×/1.5×/2×）。
- 竖版 9:16 导出同样基于该相机轨迹自动取景。

### 3.3 录制

| 快捷键 | 操作 |
|--------|------|
| F9（默认） | 开始 / 停止录制（全局热键，任意应用中可用） |
| ⏺ / ⏹ 按钮 | 控制栏点击 |

- 画面源：启动录制时选择整个屏幕或单个窗口。
- 音频：系统声音 / 麦克风 / 两者（设置中切换）。系统声音经屏幕采集回路捕获。
- 默认编码 4K 60fps VP9 WebM，可在设置中调整。
- 摄像头画中画：位置、大小、圆角、边框可在摄像头面板配置。
- 录像数据**实时落盘**：意外崩溃/断电时已录内容可恢复（下次启动会提示）。

### 3.3 导播标记与隐私保护（录制中标记，导出时生效）

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| F10 | ⏸ 暂停 / 恢复 | 暂停段自动剪除，成片时间轴无缝 |

### 纯净舞台迷你控制台

开启纯净舞台（F1）后，屏幕右下角出现悬浮控制台：开始/停止录制、画面源选择、录音切换（系统声/麦克风/全部）、摄像头开关、计时显示；标题栏可拖动、可最小化、可关闭（关闭即退出纯净舞台）。
| F6 | 🛡 隐私遮挡 | 拖拽框选屏幕上出现隐私信息的区域 → 黑框立即生效并被录进画面；系统自动**回溯定位**该内容首次出现的时刻，导出时对整段区间做同区域遮罩。再次按 F6 结束 |
| Shift+F6 | 🔒 隐私整段剪除 | 说错话/口误、或全屏私密活动（登录/输密码）：开始/结束成对标记，导出时整段剪掉 |

- 遮挡回溯失败的兜底：固定宽限窗（默认 8 秒，导出面板可调）。
- 时间轴面板列出全部标记；遮挡标记支持 ±1 秒微调起点（导出前复核）。
- 导出报告会显示"剪除 N 段共 X 秒、遮挡 N 处"。

### 3.4 快进模式（F4）

- F4 开启：画面出现 30% 黑色遮罩 + 角落"⏩ 快进中"徽标 + 中央提示，音频静音，镜头冻结。
- 再次按 F4 结束。导出时该段**无论多长强制压缩至 3–5 秒**，音频替换为轻量"嗖嗖"音效。

### 3.5 实时标注特效

特效渲染在全屏透明覆盖层上，随屏幕一起直接录进视频。

| 快捷键（默认） | 特效 | 说明 |
|----------------|------|------|
| Ctrl+1 | 🔍 放大镜 | 光标处局部放大，支持多档位 |
| Ctrl+2 | ①②③ 步骤序号 | 每次点击生成一个编号标记 |
| Ctrl+3 | 🖍 荧光笔 | 光标跟随的高亮指示 |
| Ctrl+R | 💧 点击涟漪 | 鼠标点击产生扩散圆环 |
| Ctrl+4/5/6 | 缩放档位 | 快速切换放大倍率 |
| = | 缩放循环 | 循环切换缩放级别 |

标注模式下按 ESC 退出；主窗口未聚焦时点击检测依然生效。

### 3.6 导出

在 📦 Export 面板配置：

| 选项 | 说明 |
|------|------|
| **Silence Trim** | 静音裁剪（低于阈值的静音段被移除） |
| **响度归一** | EBU R128 响度标准化，成片音量一致 |
| **竖版 9:16** | 同时导出竖版（按录制时的镜头轨迹自动取景） |
| **烧录字幕** | 本地 whisper 识别 + 可选 LLM 在线校正（改错字，不动时间戳） |
| **字幕样式** | 字体、字号、颜色、描边、位置（底/中/顶）、边距 |
| **热词表** | 每行一个专有名词，注入识别与校正提示词，技术名词准确率显著提升 |
| **附加品牌片尾** | 成片结尾自动附加 2.8 秒「简录 EaseRec」品牌动画（跟随界面语言显示中/英文案），默认开启 |
| **Output** | 输出目录 |

导出格式：MP4（H.264 + AAC，兼容 B站/YouTube 直接上传）。
导出完成后若启用了 LLM，可一键"生成章节与投稿文案"（标题/简介/标签/章节，自动保存 `_info.md`）。

首次使用字幕功能需执行 `powershell -File scripts/download-whisper.ps1`（自动镜像下载 whisper-cli + ggml 模型）。

### 3.7 快捷键自定义

所有快捷键可在设置面板修改，配置持久化于 `~/DirectorCam/shortcuts.json`（或 UI 保存后的 settings.json）。若某个 F 键被其他软件占用，DirectorCam 会自动以底层输入轮询兜底，快捷键依旧全局有效。

## 四、录制最佳实践

1. **准备** → F1 纯净舞台，点预览区"画面源"选全屏或窗口，设置里确认帧率/分辨率
2. **录制** → F9（3-2-1 倒数后开始，主窗自动最小化，迷你窗可控制）
3. **口误** → Shift+F6 隐私段成对标记剪掉；**喘口气** → F10 暂停（暂停段自动剪除）
4. **隐私信息出现** → F6 框选遮挡（自动回溯）；私密操作 → Shift+F6 整段剪除
5. **漫长等待** → F4 快进
6. **强调** → Ctrl+1/2/3/R 特效；📸 随时截图
7. **结束** → F9 停止 → 自动回放
8. **导出** → 右下"📦 导出成片" → 一键 MP4（可选竖版/字幕/片头片尾）

## 五、常见问题

**Q: 启动后画面/预览是黑的？**
A: 1) 确认授予了屏幕采集权限并重新选择画面源；2) 部分受 DRM 保护的内容（如 Netflix）无法被采集，属系统限制；3) 更新显卡驱动。

**Q: 导出失败 / 提示 FFmpeg not found？**
A: 确认 `src-tauri/ffmpeg.exe` 存在，或运行 `scripts/download-ffmpeg.ps1`。

**Q: 全局快捷键无效？**
A: 可能被其他应用占用（尤其是裸 F 键）。可在设置中换键；窗口内按键始终有效。

**Q: CPU 占用高？**
A: 降低分辨率/帧率，关闭不需要的特效。4K 60fps 下目标是 CPU < 5%。

**Q: 远程桌面 (RDP) 下能录吗？**
A: 基本可用，但画面源枚举和性能与本地有差异，正式录制建议本地运行。

## 六、与旧版（Tauri）的差异

本项目已从 Tauri 迁移至 Electron，行为差异：

- **无需管理员权限**（旧版 DXGI 采集要求管理员，新版不再需要）。
- 启动命令改为 `npm run dev`（旧版为 `npm run tauri dev`）。
- 倒带/隐私/快进/暂停统一为"录制时打标记 + 导出时剪辑"架构（见 ROADMAP）；v0.2 起独立的"倒带 3/5 秒"快捷键已移除（口误请用 Shift+F6 成对标记或 F10 暂停）。
- Studio Mode 桌面级功能已恢复（隐藏图标 + 底层背景）；16:9 窗口排布暂未恢复。
